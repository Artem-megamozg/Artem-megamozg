## 🧠 Обо мне

Разрабатываю **ML/AI и backend-системы на Python**, совмещая Data Science с полноценной разработкой программных продуктов.

Работаю с задачами от анализа и подготовки данных до обучения моделей, построения API, интеграции нейросетей и развёртывания готовых решений.
